# What you Found in Here ? 

Welcome to my cybersecurity blog, where I document my journey through offensive security, penetration testing, and hands-on labs. This is a place for sharing technical write-ups, research, practical techniques, and lessons learned while exploring real-world security challenges. Topics covered here include web application security, Linux and Windows privilege escalation, Active Directory attacks, penetration testing, vulnerability research, and Capture The Flag (CTF) challenges. You’ll find walkthroughs, enumeration techniques, exploitation methodologies, and notes from platforms such as Hack The Box, TryHackMe, PortSwigger Web Security Academy, and VulnLab. My goal is to break down complex security concepts into practical, understandable explanations that help other aspiring penetration testers learn, improve, and think like security professionals.

# Who Am I ? (Summary)

I'm a cybersecurity enthusiast and penetration tester focused on offensive security and vulnerability assessment. I have hands-on experience with penetration testing, bug bounty hunting, and security labs, with a particular interest in discovering vulnerabilities and understanding how systems can be compromised and secured. My main areas of interest are web application penetration testing, Linux and Windows security, Active Directory enumeration and exploitation, privilege escalation, and vulnerability research. I enjoy solving challenging machines, investigating unfamiliar technologies, and documenting the techniques I learn along the way.This blog serves as my technical knowledge base—a place to document research, share findings, and continuously develop my skills in offensive security.
